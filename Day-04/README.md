# Day 4 - Stack and Queue Data Structures

## Overview

On Day 4 of Campus Recruitment Training (CRT), I learned and implemented two important linear data structures: **Stack** and **Queue**.

The session focused on understanding their working principles, operations, and different implementation techniques using Java.

---

## Topics Covered

### 1. Stack Data Structure

A Stack follows the **LIFO (Last In First Out)** principle.

Example:

```text
Push: 10, 20, 30

Top
 ↓
30
20
10

Pop → 30
```

#### Operations Implemented

- Push
- Pop
- Peek
- Traverse / Display
- Stack Overflow
- Stack Underflow

### 4. Queue Data Structure

A Queue follows the **FIFO (First In First Out)** principle.

Example:

```text
Insert: 10, 20, 30

Front → 10 20 30 ← Rear

Delete → 10
```

#### Operations Implemented

- Insert (Enqueue)
- Delete (Dequeue)
- Peek
- Display

---
