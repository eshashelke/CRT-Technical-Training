# Day 2 - Searching and Sorting Algorithms

## Overview

The second day of Campus Recruitment Training focused on understanding and implementing fundamental searching and sorting techniques in Java. These algorithms are widely used in software development and frequently appear in coding interviews and placement assessments.

---

## Topics Covered

### 1. Binary Search

Implemented Binary Search on a sorted array to efficiently locate a target element.

**Key Concepts:**
- Divide and Conquer
- Searching in Sorted Arrays
- Time Complexity: O(log n)

---

### 2. Bubble Sort

Implemented Bubble Sort to arrange elements by repeatedly swapping adjacent elements.

**Key Concepts:**
- Comparison-Based Sorting
- Multiple Passes Through Array
- Time Complexity: O(n²)

---

### 3. Selection Sort

Implemented Selection Sort by repeatedly selecting the smallest element and placing it in its correct position.

**Key Concepts:**
- In-Place Sorting
- Minimum Element Selection
- Time Complexity: O(n²)

---

### 4. Merge Two Sorted Arrays

Merged two already sorted arrays into a single sorted array.

**Key Concepts:**
- Array Traversal
- Two-Pointer Technique
- Ordered Data Processing

---

### 5. Merge Sort

Implemented Merge Sort using recursion and divide-and-conquer strategy.

**Key Concepts:**
- Recursion
- Divide and Conquer
- Stable Sorting
- Time Complexity: O(n log n)

---
