# Day 1 - Basic Programming and Recursion

## Overview

The first day of Campus Recruitment Training focused on strengthening fundamental programming concepts using Java. The session covered number manipulation, array operations, and recursive problem-solving techniques.

---

## Topics Covered

### 1. Reverse a Number

Implemented logic to reverse a three-digit number using arithmetic operations.

### 2. Array Insertion

Inserted a new element into an array at a user-specified location by shifting existing elements to the right.

### 3. Maximum and Minimum Element in an Array

Traversed the array to identify the largest and smallest elements.

### 4. Recursion

Implemented recursive solutions for:

- Factorial Calculation
- Multiplication Using Repeated Addition
- Power Calculation
- Sum of First N Natural Numbers
