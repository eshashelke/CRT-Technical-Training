# Day 3 - Singly Linked List Operations in Java

## Overview

On Day 3 of Campus Recruitment Training (CRT), I learned and implemented the Singly Linked List data structure in Java.

A linked list is a dynamic data structure where elements (nodes) are connected using references. Unlike arrays, linked lists do not require contiguous memory allocation, making insertion and deletion operations more flexible.

This program is menu-driven and allows users to perform various linked list operations interactively.

---

## Topics Covered

### 1. Node Creation

Created a custom node structure containing:

- Data field
- Reference to the next node

### 2. Append Operation

Adds a new node at the end of the linked list.

### 3. Insert at Beginning

Adds a new node at the start of the linked list by updating the head pointer.

### 4. Insert After a Given Node

Inserts a new node after a specified key value in the list.

### 5. Traversal

Displays all elements of the linked list in sequence.

Example:

```text
10 -> 20 -> 30 -> 40
```

### 6. Delete at Beginning

Removes the first node from the linked list.

### 7. Delete at End

Removes the last node from the linked list.

### 8. Size of Linked List

Calculates and displays the total number of nodes present in the linked list.

### 9. Search Operation

Searches for a given value in the linked list and displays its position if found.
